# Telegram Overlay Translator для Android

Полноценное приложение для Android, реализующее функцию **плавающего экранного переводчика поверх Telegram** (и любых других чатов).

---

## 📱 Как это работает

1. **Accessibility Service (Служба специальных возможностей):**
   - Приложение инспектирует активное окно системы и обходит дерево элементов (`AccessibilityNodeInfo`).
   - Извлекает текстовые блоки сообщений из диалогов Telegram без необходимости взламывать или модифицировать клиент Telegram, и **без root-прав**.
   - Фильтрует сообщения: игнорирует временные метки ("12:45"), знаки препинания и текст, который уже написан на русском языке (`[а-яА-ЯёЁ]`).

2. **Overlay / WindowManager («Поверх других окон»):**
   - Использует системный оверлей `TYPE_APPLICATION_OVERLAY` с флагом `FLAG_NOT_FOCUSABLE`.
   - Отображает плавающий круглый значок (Bubble), который можно свободно перетаскивать пальцем по экрану (он автоматически примагничивается к краю).
   - При нажатии на значок считывает экран диалога и открывает красивую всплывающую карточку с переводом на русский язык.
   - Есть кнопка быстрого копирования любого переведенного сообщения в буфер обмена.

3. **Движок перевода (`GoogleTranslateApi` + `TranslationRepository`):**
   - Использует прямой шлюз Google Translate (GTX), работающий мгновенно и **без необходимости регистрировать платные API-ключи**.
   - Встроенный LRU-кэш: при прокрутке чата вверх и вниз уже переведенные сообщения не запрашиваются повторно, экономя трафик и батарею.

## 🚀 Как запустить и собрать APK

### Способ 1: Через Android Studio (Рекомендуется)
1. Откройте **Android Studio** (Hedgehog, Iguana, Jellyfish, Koala или новее).
2. Выберите **File → Open** и укажите данную папку проекта (`d:\игра яндекс`).
3. Дождитесь автоматической синхронизации Gradle (Gradle Sync).
4. Подключите ваш Android-смартфон по USB (включив «Отладку по USB» в настройках разработчика) или запустите эмулятор.
5. Нажмите кнопку **Run (Shift + F10)**.
6. Для сборки готового `.apk` файла:
   - В верхнем меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
   - Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`. Его можно просто отправить себе в Telegram (в «Избранное») и установить на телефоне.

## ⚙️ Пошаговая настройка на смартфоне

После установки приложения на телефон:
1. Запустите приложение **TG Translator Overlay**.
2. В блоке «Необходимые разрешения»:
   - Нажмите **«Включить»** напротив *Поверх других окон* → переведите тумблер в активное положение.
   - Нажмите **«Включить»** напротив *Спец. возможности* → в открывшемся системном меню перейдите в «Скачанные приложения» (или «Установленные службы») → найдите **TG Translator Overlay** и включите его.
3. Нажмите большую кнопку **«Запустить плавающую кнопку»** — на экране появится синий круглый значок с иконкой перевода.
4. Откройте **Telegram** в любом англоязычном чате или канале.
5. Нажмите на плавающую кнопку — приложение мгновенно считает видимый текст сообщений и выведет русский перевод прямо поверх экрана!

## 💡 Особенности прошивок (Xiaomi, Samsung, Realme)

- **Xiaomi / Redmi / POCO (MIUI / HyperOS):**
  - Зайдите в *Настройки → Приложения → TG Translator Overlay*.
  - Включите **«Автозапуск»** и **«Другие разрешения» → «Отображать всплывающие окна»**.
  - В пункте «Контроль активности» выберите **«Нет ограничений»** (чтобы система не закрывала службу в фоне).
- **Samsung OneUI:**
  - В настройках приложения отключите «Перевод в режим сна».
